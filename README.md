# VICE HORIZON

A top-down open-world crime story in Pearl City, Florida. Cruise seven districts, take on fourteen-plus contacts, and make your own way through the city.

| Input | Action |
| --- | --- |
| WASD / arrows | Move, steer, accelerate and brake |
| Shift | Sprint / drift |
| F | Enter or exit a vehicle |
| Mouse / Space | Aim and attack |
| 1-3 / Q-E | Select weapon |
| Enter | Start or accept a contract |
| H / P / Esc | Controls / pause |
| M | Toggle radio |
| F5 / F9 | Save / load |

## Run

Run the local static server with:

```sh
node serve.ts
```

Then open http://localhost:8080.
