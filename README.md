# VICE HORIZON

VICE HORIZON is a deterministic top-down open-world crime game set in Pearl City, Florida. Explore neon districts, steal cars, run contracts, evade police, and build a reputation across fourteen connected jobs.

## Controls
WASD or arrows move and drive. F enters or exits cars. Space fires. Shift sprints or handbrakes. Q/E changes weapons. Enter accepts a contract. P pauses, H opens help, M mutes audio, and L loads the local save.

## Run it

`node serve.ts`

Open http://localhost:8080. Deterministic scenes are available with `?shot=start`, `?shot=play`, `?shot=chase`, or `?shot=mission` and an optional `&seed=1`.
